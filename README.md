Tech stacks dan alasan:

-   **Vite:** Digunakan sebagai build tool dan dev server yang cepat dengan Hot Module Replacement.
    
-   **React:** Digunakan untuk membangun UI berbasis komponen yang modular dan interaktif.
    
-   **Ant Design (antd):** Digunakan untuk membuat komponen UI profesional, responsif, dan konsisten tanpa membuat styling dari awal.
    
-   **Vitest:** Digunakan untuk unit testing komponen dan fungsi dengan integrasi yang mudah ke Vite.
    
-   **TypeScript:** Digunakan untuk menambahkan tipe statis agar lebih aman dari bug dan lebih mudah dipelihara.
